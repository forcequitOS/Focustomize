**Public Beta available now!**

## This project is effectively discontinued, here's its eulogy.
I *have* finally open-sourced this, and publicly released what remains, so others can learn from the work I did put into it. The final public beta, which I'm dubbing "The Finale" has some broken features, but does include some things that haven't seen the light of day yet, and this was very heavily vibe-coded since I was really new to Swift, SwiftUI, and development as a whole. It was a decent learning experience.

This isn't necessarily a permanent discontinuation, I may pick this up again someday, but I probably would have to rewrite it, or at the very least rewrite a large chunk of it, and this was already truthfully just a rather complex app for what it is.

I encourage you to probably *not* use this? But, if you want to, the latest version has support for macOS 26 Tahoe, with a Liquid Glass icon and all. 

### How do I install it?
```
bash -c "$(curl -sSL https://github.com/forcequitOS/Focustomize/raw/main/install.sh)"
```
if you're cool...or just download the [latest release](https://github.com/forcequitOS/Focustomize/releases/latest/), extract it, copy to /Applications, ignore macOS' warnings, and run.

### How does this work?

By modifying ~/Library/DoNotDisturb/DB/ModeConfigurations.json.

### What can it do?

25 extra Focus mode colors, any SF Symbol icon you could want under the sun, and names way longer than Apple would have ever wanted (now featuring line breaks!)
